三、产出物一：PRD（需求说明书）
3.1 用户画像

用户类型：个人用户 / 家庭用户 / 小规模共享用户

技术水平：非技术背景为主

使用频率：每日 1–3 次

使用场景语言：多语言环境（中 / 日 / 英）

3.2 使用场景

场景 1：记录日常收入与支出（多币种）

场景 2：跨币种资产的统一查看（自动汇率换算）

场景 3：家庭 / 多人共享账本协作记账

场景 4：定期支出（房租、订阅）自动登记

场景 5：预算控制与超支提醒

场景 6：按条件筛选并生成报表分析

3.3 功能需求（Functional Requirements）
FR-01 账户与账本管理

用户可通过邮箱注册与登录

支持创建多个账本

账本可设置为个人或共享

FR-02 多人共享账本

支持多个用户加入同一账本

不同用户可被分配不同权限（查看 / 记录 / 管理）

FR-03 多语言支持

系统支持多语言界面（至少中 / 日 / 英）

语言切换不影响数据本身

FR-04 多币种与汇率换算

支持多币种记账

系统基于统一基准币种进行汇总

汇率可自动更新并记录使用时点

FR-05 收入与支出记录

支持设置消费类别

每一笔交易必须关联类别与币种

FR-06 定期支出自动登记

用户可设置周期性支出规则

系统按规则自动生成交易记录

FR-07 预算管理

支持整体预算设置

支持按消费类别设置预算

超过预算时给予提示

FR-08 查询、筛选与导出

支持按时间、类别、金额筛选

支持账本数据导入 / 导出（CSV 等）

FR-09 报表与可视化

自动生成收支报表

支持饼状图等可视化形式

FR-10 AI 支出分析与建议（高级功能）

基于历史数据进行支出结构分析

提供简单的消费建议与趋势提示

3.4 非功能需求（Non-Functional Requirements）
NFR-01 数据一致性

所有金额变更必须在事务中完成

不允许出现跨币种计算错误

NFR-02 并发与共享安全

多用户同时操作时数据保持一致

NFR-03 可扩展性

新币种、新语言、新分析模块可平滑扩展

NFR-04 可审计性

汇率来源与更新时间可追溯
